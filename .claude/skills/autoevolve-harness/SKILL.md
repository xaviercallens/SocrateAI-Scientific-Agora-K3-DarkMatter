# AutoEvolve Harness (Stream 2)

AutoEvolve explores and scores. It does not decide, and its preferences are never
evidence. Every verdict must decompose into checker certificates a reader can audit.

## Invariants (violating any of these invalidates the run)

1. **Scores come from certificates only.** The scoring function reads
   `certificates/*.json`; it never recomputes criterion mathematics internally and never
   calls a model.
2. **Weights are frozen.** Read from the weights block of `K3_CRITERIA.md` (or its
   pinned companion file), hash-checked at startup. A runtime weight change aborts the run.
3. **Reproducible.** Every run takes an explicit `--seed` and writes
   `runs/<timestamp>/config.json` containing: seed, criteria-file SHA256, checker
   versions, candidate set. The reproducibility CI job replays the latest run and diffs
   scores bit-for-bit.
4. **Hard criteria are gates, not weights.** A candidate with a hard-criterion FAIL is
   excluded before scoring (F1), regardless of how well it scores elsewhere.
5. **Post-freeze criteria changes demote results.** If `K3_CRITERIA.md` was amended
   after a run, that run's outputs are labeled `EXPLORATORY` in all reports (amendment
   protocol §6). Check `git log` on the criteria file before citing any run.

## Run procedure

```
python autoevolve/run_ranking.py \
  --criteria K3_CRITERIA.md --certificates certificates/ \
  --seed <int> --out runs/<date>/
python scripts/render_selection_report.py runs/<date>/   # machine-generated tables
```

Then reproduce once with the same seed and diff before reporting anything.

## Reporting rules

- `K3_SELECTION_REPORT.md` evidence tables are generated by
  `render_selection_report.py` only. Prose may interpret the tables; it may not
  introduce numbers absent from them.
- The phrase "AutoEvolve preferred/selected X" is banned in isolation — always
  "X passed hard criteria {…} and scored … on soft criteria {…} (run <id>)".
- Adversarial memos (WP S2-05) are answered point-by-point in writing; an unanswered
  memo blocks the report.
