## Why 11, not the guide's aspirational "≥15"

Every row traces to a citation already hash-pinned and read in this repo (Cooper 2012,
Almkvist–van Straten arXiv:2103.08651, Gorodetsky arXiv:2102.11839, Beukers–Stienstra 1985,
Beukers 1983, Beukers–Peters 1984). Padding to 15 with less-verified entries would have
meant either fresh, unrushed web verification (the LR-4 standard — real, but more effort
than this pass budgeted) or accepting weaker sourcing to hit a round number. Chose honesty
over the count. Extending this table is a legitimate follow-on task, not deferred out of
laziness — see `briefs/LOW_TIER_QUEUE_2026_08_01.md` item B-S2-3 (S3 repo) for the reasoning
this decision follows.

yet either way, so a ruling alone wouldn't populate a row; that would still need the actual
recurrence/citation added to `refs/recurrences_v1.json` first, which is Track A's own
domain, not this sandboxed task's.
