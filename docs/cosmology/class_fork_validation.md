## 2. Architectural finding: CLASS's public fld module cannot represent this model directly

`rho_DM(a) ∝ a^{-3-ε}` (scientificplan.md T5.2) implies an equation of state w_DM = ε/3 ≈ 0.00837 (positive). Attempting this via CLASS's native dark-energy fluid API (`Omega_fld`, `w0_fld`, `cs2_fld`) raises a hard error (confirmed live, not from memory): `Error in Class: perturbations_init(L:776) :condition (w_fld_ini >= 0.) is true; The fluid is meant to be negligible at early time, and unimportant for defining the initial conditions of other species. You are using parameters for which this assumption may break down, since at early times you have w_fld(a--->0) = 8.370000e-03 >= 0`

This is architectural, not a parameter-tuning issue: CLASS's perturbation initial-condition code assumes any `fld` species is negligible at early times (w<0 required), which is fundamentally incompatible with a component that dilutes *faster* than matter (w>0) and therefore grows in relative importance at a->0. A literal implementation requires patching CLASS's C source (`background.c`'s CDM density law and `perturbations.c`'s CDM continuity/Euler equations) and recompiling — a genuine "CLASS fork" in the sense the task names it. That patch is NOT attempted here: unlike the GAP-3 Dolan solver (validated against 6 independent published data points), a custom perturbation-equation patch would have no independent benchmark to validate against, and shipping an unverified custom Boltzmann patch as ground truth would repeat exactly the kind of unverified-claim failure this session already caught twice (GAP-1's weight-2 bound, GAP-3's 86.6 Myr figure). This is flagged as required follow-up work.

**Key finding:** applying epsilon=0.02511 consistently to BOTH the sound-horizon integral and the comoving-distance integral (both depend on the same modified H(a)) and solving for the H₀ that preserves the real-CLASS-computed acoustic scale gives **H₀ ≈ 75.81 km/s/Mpc**, not the previously-claimed 71.92. This is a real, substantive discrepancy (~+3.9 km/s/Mpc), and notably OVERSHOOTS even the SH0ES local measurement (~73 km/s/Mpc) rather than landing between Planck and SH0ES as the model intends.

A diagnostic check — deliberately using the STANDARD (epsilon=0) sound horizon together with the epsilon-modified comoving distance (an internally *inconsistent* shortcut) — gives H₀ = 60.95 km/s/Mpc instead, which is also far from 71.92. Neither the fully self-consistent nor this particular inconsistent-shortcut calculation reproduces the ledger's number; the exact method behind the original epsilon=0.02511 → H₀=71.92 fit (LL.md:94) is not fully documented/reproducible from what's in the repository. Per Rule 1, this discrepancy is reported rather than silently reconciled.

## 4. Supplementary: effective-LCDM proxy Cl^TT (illustrative only)

An LCDM proxy (H₀_eff=58.85, ω_cdm_eff=0.1461) was fit via real CLASS to reproduce the SAME (r_s, D_M) as the self-consistent ε-model above. **This requires boosting ω_cdm by 22% above the true model's own value (0.12)** — which by itself shows this proxy technique conflates a redshift-*scaling* change (what ε actually does) with a density-*normalization* change, and should NOT be read as a genuine prediction of the true model's CMB peak heights. Its Cl^TT deviates from the baseline by up to **17%** (at ℓ≈2) — this number is dominated by the artificial ω_cdm boost, not physical content, and is reported only as a concrete illustration of why this shortcut is untrustworthy for peak heights, not as the model's actual Cl^TT deviation.
