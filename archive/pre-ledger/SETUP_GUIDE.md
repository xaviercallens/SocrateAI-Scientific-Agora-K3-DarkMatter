## Manual Setup Required

### 1. Create GitHub Project Board
Go to repository -> Projects tab -> New Project -> Board
Name: Dual-Scale Topological Universe Model
Description: Tracking progress across Theory, K3 Selection, and Experimentation

### 2. Add Columns
- Backlog
- To Do
- In Progress
- Done
- Validation
- Blocked

### 3. Add Issues to Project
For each issue, add it to the project and assign to appropriate column.

### 4. Create Milestones
Create 6 milestones (M1-M6) with due dates from 2026-08-17 to 2027-01-17.

### 5. Optional: Branch Protection
Settings -> Branches -> Add rule for main branch.

### 6. Optional: Collaborators
Settings -> Collaborators -> Add team members.
